# Uso sin conexión

La interfaz es una aplicación web progresiva. Después de una primera visita en línea, el navegador puede conservar la página y algunos recursos estáticos en caché.

La consulta y edición de rutas, salones y fotos requiere la API PHP y las bases SQLite del servidor. Guardar cambios o subir fotos sin conexión no está soportado; vuelve a conectarte y confirma que el servidor esté disponible antes de editar.

Para actualizar la aplicación instalada, ábrela con conexión para que el navegador descargue la versión nueva.
